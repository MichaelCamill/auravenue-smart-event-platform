# PromptWars x Hack Sprint - Workspace Rules & Instructions

Always adhere to these event-specific hackathon guidelines and submission requirements for this workspace:

---

## 🏆 Event Profile: PromptWars x Hack Sprint
- **Organizers**: HackuVerse in collaboration with **Google for Developers** & **Hack2skill**.
- **Format**: AI Vibe Coding Challenge with a **surprise real-world problem statement**.
- **Hack Sprint Window**: **06 Sep 2026, 08:00 AM IST – 06 Sep 2026, 05:00 PM IST (9-Hour Rapid Sprint)**.
- **Finale & Evaluation**: 07 Sep 2026, 05:00 PM – 06:00 PM IST.
- **Core Focus**: Rapid AI prototyping, prompt engineering, Google AI/Gemini tools, and real-world impact.

---

## 📋 Mandatory Submission Requirements

### 1. Public Demo Link (Zero-Barrier Access)
- The deployed web application MUST be 100% publicly accessible.
- **Zero Login / Authentication Walls**: Evaluators must be able to view and test all core AI features without logging in, signing up, or providing API keys.
- **1-Click Guest / Demo Mode**: Implement pre-populated sample inputs and test presets for instant evaluation.
- **High-Availability Hosting**: Deploy to Vercel, Netlify, Render, or Railway.

### 2. Complete Public GitHub Repository
- The repository must be public with full source code.
- **Comprehensive README.md**:
  - Prominent project title, tagline, and live demo link at the top.
  - Explicit mapping to the surprise problem statement.
  - System architecture diagram (Mermaid) and data flow.
  - Tech stack details (highlighting Google AI / Gemini integrations).
  - Step-by-step local setup and environment configuration instructions.
  - Clean project structure and commit history.

### 3. LinkedIn Post & Pitch
- Submit a public URL to a concise LinkedIn post.
- **Problem Statement Alignment**: The post MUST explicitly map back to the specific problem statement, demonstrating exactly how the solution addresses the challenge (vague descriptions hurt alignment scoring).
- Include live demo link, GitHub repo link, and relevant tags (#PromptWars #HackSprint #GoogleForDevelopers #Hack2skill #HackuVerse #AI).

---

## ⚖️ Rules, Scoring & Quality Protocol
- **Evaluation Criteria**: Innovation, Problem-Solving Approach, Technical Implementation, User Experience (UX), Real-world Impact, and Alignment with the Problem Statement.
- **Max 2 Submission Attempts**: Only the last submitted attempt is scored.
- **Zero Broken Links**: Inaccessible, private, or broken links lead to immediate disqualification.
- **Strict Verification**: Test all URLs (Demo, GitHub Repo, LinkedIn Post) in Incognito / Private browsing mode before finalizing submission.
